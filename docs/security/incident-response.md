# Incident Response Checklist

1. Contain: disable affected organization access or revoke credentials through the platform console.
2. Preserve evidence: retain application, access, queue, and audit logs; do not edit audit records.
3. Assess: identify tenant scope, affected records, attack path, and whether secrets require rotation.
4. Eradicate: patch the defect, rotate impacted credentials, invalidate sessions/tokens, and deploy the fix.
5. Recover: verify tenant isolation, audit-log integrity, backups, and core HR workflows.
6. Communicate: follow contractual and legal breach-notification requirements.
7. Review: document root cause, timeline, corrective actions, and regression tests.
